Button

The primary interactive element. Composed of a variant (color intent — default, brand, error, info, success, warning, aiden) and a style (visual weight — default, secondary, outline, ghost, link). Add size (small / default / large), isLoading for a spinner state, disabled for the inactive state, and IconLeft / IconRight / IconCenter (with iconOnly) for icons.

Variants × styles

Every variant × style combination. aiden is intentionally restricted to default and outline styles.

Sizes

Three sizes: small, default, large. Applies to every variant × style.

States

Loading (spinner replaces content), disabled, with icons, and icon-only.

Theme scope

Wrap a subtree in data-theme="{code}" and the default (primary) button takes that theme's color automatically. Secondary / outline / ghost / link stay neutral slate.

data-theme="db" — DB, Indigo
data-theme="nb" — NB, Emerald
