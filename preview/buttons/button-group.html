ButtonGroup

Wraps a set of related buttons so their touching corners flatten and their borders collapse into a single visual unit. Two orientations: horizontal (default) and vertical. Compose with ButtonGroupSeparator for visual dividers, and ButtonGroupText for non-button labels inline with the group.

Horizontal

Default orientation. Corners of interior buttons flatten automatically.

Vertical

Stacks buttons top-to-bottom. Same corner-flatten behavior on the vertical axis.

With separator

ButtonGroupSeparator is a thin divider. Use to group logically-distinct buttons within a single group (e.g. undo/redo separated from cut/copy/paste).

With inline text

ButtonGroupText lets you embed a label or count in the group. Useful for quantity spinners and pagination.
