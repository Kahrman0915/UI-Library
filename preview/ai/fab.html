Fab

The floating action button — a viewport-pinned launcher for the one action that should always be within reach. It fills with --primary, so it picks up whatever brand it sits in; wrap it in data-surface="aiden" and it becomes the Aiden gradient, which is the launcher this system was built for. Use it for a single always-available entry point, never for a row of options.

Setup

import { Fab } from '@ui/lib';
import { Sparkles } from 'lucide-react';

<Fab id="ask-aiden" position="bottom-right" pulse badge="2" aria-label="Ask Aiden">
  <Sparkles />
</Fab>

Sizes

default — 48px
lg — 56px (default)

Pulse and badge

pulse adds expanding halo rings that draw the eye without moving the button; badge takes a count. The halo is suppressed entirely when the FAB is disabled — rings advertising an action you cannot take are worse than no rings.

pulse + badge
disabled — no rings

Neutral, or the Aiden surface

On its own the FAB is --primary — neutral slate on the main brand, the host brand's colour inside a data-theme. The gradient is not a default: it comes from data-surface="aiden", which layers inside any brand rather than replacing it.

default — --primary
inside data-theme="db"
data-surface="aiden" — the gradient

Placement

position pins it to one of four viewport corners, inset --p-6 from both edges. bottom-right is the default and the one to reach for — it sits under the thumb on touch and out of the reading path on desktop.
