The Aiden conversation family — 27 exports covering the transcript, the composer, tool-call cards, reasoning blocks, citations and sources. Content is consumer-provided JSX: there is no Markdown parser, because that would mean a runtime dependency the library does not take.

The transcript

Claude-style, not iMessage-style: the assistant answers as full-width, bubble-less prose and only the user's turns sit in a contained bubble on the trailing edge. Uniform corners, no tails, no per-message avatars — a centred max-w-3xl column that reads as a document.

Pending and streaming

pending shows typing dots before any content arrives; streaming appends a blinking caret to content already being written. They are different states and should not be used together.

Tool calls and reasoning

Agent actions surface as collapsible cards so an answer stays inspectable — status is running / success / error. The reasoning block is the same shape for "thinking" text.

The composer

Reuses the shared .ui-input-wrap field chrome and autosizes to its content up to a cap. Enter sends, Shift+Enter inserts a newline. Send composes Button variant="aiden", so it carries the gradient under any brand — and swaps to a stop control while a response is streaming.
