FeaturedIcon

The boxed icon tile — a lucide glyph on a tinted, bordered surface. Sizes sm / default / lg, shapes square / circle, and one variant per semantic colour. Empty composes this rather than hand-rolling its own tile.

Setup

import { FeaturedIcon } from '@ui/lib';
import { Sparkles } from 'lucide-react';

<FeaturedIcon Icon={Sparkles} variant="brand" size="lg" />
