Kbd

A keycap for keyboard shortcuts — a styled <kbd> with a monospace face and a raised bottom border. Sizes sm / default / lg. Compose several inline to spell a chord.

Setup

import { Kbd } from '@ui/lib';

Press <Kbd>⌘</Kbd> <Kbd>K</Kbd> to search.

Sizes

S D L

Chords

⌘ K — open command palette
⌘ ⇧ P — quick actions
Ctrl C — copy
Press Esc to close.
