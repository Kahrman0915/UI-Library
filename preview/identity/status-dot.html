StatusDot

A small presence indicator — online, away, busy, offline, or neutral — mapped to the semantic colour tokens. Optional pulse emits a soft expanding ring for live states (suppressed under prefers-reduced-motion). Give it a label and it exposes role="status"; without one it's aria-hidden decoration beside a visible label.

Setup

import { StatusDot } from '@ui/lib';

<StatusDot status="online" label="Online" />
<StatusDot status="busy" pulse label="Recording" />
