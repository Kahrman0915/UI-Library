Label

The primitive that every form control's built-in label composes. Renders a native <label> with htmlFor association, plus an optional description below and a required flag that adds a * in --error. Three sizes match Input / Textarea / Field sizing (sm, default, lg). Also honors disabled so the label greys out with its target control.

Sizes

Three sizes; use the one that matches the paired control.

Required + description

required renders a * in the error color as a compact indicator. description stacks a smaller, muted helper line under the label.

Disabled

Greyed to --muted-foreground when the paired control is disabled. Cursor becomes not-allowed.

Composition with a control

Every form-control component in the library (Input, Textarea, Field, Checkbox, etc.) composes Label internally. Pass its props directly on the control (see the Input card) rather than mounting Label separately unless you need a custom layout.
