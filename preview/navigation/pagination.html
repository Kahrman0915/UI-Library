Pagination

Page navigation for lists, tables, and search results. A compound of Pagination (a labelled <nav>) → Content (<ul>) → Item → Link / Previous / Next / Ellipsis. Cells reuse the Button visual (ghost, outline when active), the active page carries aria-current="page", prev/next expose accessible names, and the ellipsis hides a "More pages" label for screen readers.

Setup

import {
  Pagination, PaginationContent, PaginationItem,
  PaginationLink, PaginationPrevious, PaginationNext, PaginationEllipsis,
} from '@ui/lib';

<Pagination>
  <PaginationContent>
    <PaginationItem><PaginationPrevious href="#" /></PaginationItem>
    <PaginationItem><PaginationLink href="#" isActive>2</PaginationLink></PaginationItem>
    <PaginationItem><PaginationNext href="#" /></PaginationItem>
  </PaginationContent>
</Pagination>
