Sidebar

The full app-navigation subsystem — around 21 parts plus a SidebarProvider and a useSidebar hook. It ships its own --sidebar-* token surface (neutral chrome, deliberately not remapped by data-theme), persists its open/closed state to localStorage, and binds ⌘B to toggle.

Collapse works as an in-flow gap spacer plus a viewport-fixed panel, both driven by data-state and data-collapsible on the wrapper — no JS measurement. Below 768px it swaps itself out for a Drawer; in icon mode each row grows a Tooltip, and SidebarMenuSkeleton covers the loading pass.

Setup

import {
  SidebarProvider, Sidebar, SidebarHeader, SidebarContent, SidebarFooter,
  SidebarGroup, SidebarGroupLabel, SidebarGroupContent,
  SidebarMenu, SidebarMenuItem, SidebarMenuButton, SidebarInset, SidebarTrigger,
} from '@ui/lib';

<SidebarProvider>
  <Sidebar collapsible="icon">
    <SidebarHeader>…</SidebarHeader>
    <SidebarContent>
      <SidebarGroup>
        <SidebarGroupLabel>Platform</SidebarGroupLabel>
        <SidebarGroupContent>
          <SidebarMenu>
            <SidebarMenuItem>
              <SidebarMenuButton isActive>Home</SidebarMenuButton>
            </SidebarMenuItem>
          </SidebarMenu>
        </SidebarGroupContent>
      </SidebarGroup>
    </SidebarContent>
  </Sidebar>
  <SidebarInset><SidebarTrigger />…</SidebarInset>
</SidebarProvider>

Expanded

The full anatomy: a header with a large branded row and a search input, grouped menus with badges, row actions and a nested sub-menu, then a footer for account links. The active row uses --sidebar-accent.

Home
Page content sits in SidebarInset. The sidebar reserves its width through an in-flow gap spacer, so the layout never jumps when it collapses.

Collapsed to icons

With collapsible="icon" the panel narrows to --sidebar-width-icon (3rem) and the labels drop away, leaving the glyphs. Each row gets a Tooltip in this state so the destination is still readable. Use collapsible="offcanvas" to slide it fully out instead.

Collapsed
Only the glyphs remain. ⌘B toggles between the two states, and the choice is remembered across reloads.

Right side

side="right" mirrors the whole subsystem — useful for an inspector or properties panel opposite the main navigation.
