Item

Universal list-row primitive. Renders as <a> if given href, <button> if given onClick, <div> otherwise. Three variants (default, outline, muted) × three sizes (xs, sm, default). Composed of slots: ItemMedia (leading icon/image), ItemContent (title+description), ItemActions (trailing buttons), plus optional ItemHeader / ItemFooter. Group with ItemGroup and separate with ItemSeparator.

Basic anatomy

Media + Content + Actions. This one is interactive (href) so hover/focus styles apply.

Design tokens
Spacing, colors, radii, shadows — the atomic style values.

Variants

default is chromeless. outline adds a border. muted adds a soft --muted background — useful in busy lists.

Bulleted list

ItemMedia variant="bullet" draws a small disc that sits on the first text line, so a wrapping bullet stays hung. Put the text straight into ItemContent — ItemTitle truncates to one line. This is the prose list; use Item with a title and description for settings rows instead.
