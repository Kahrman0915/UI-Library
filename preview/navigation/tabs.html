Tabs

Compound component for switching between related panels. Root controls the active value (controlled or uncontrolled via defaultValue). TabsList is the tab strip; TabsTrigger is each tab; TabsContent the corresponding panel. Handles arrow-key navigation, Home / End, and automatic vs manual activation. Two orientations.

Horizontal

Default orientation. Left/right arrows move focus between triggers; the underline slides to the active tab.

The overview panel is active. Panels are unmounted when inactive unless forceMount is set.

Vertical

Set orientation="vertical" for a sidebar-style tab list. Arrow-up/down navigate; the active indicator moves to the right edge of the list.

Notifications panel. In vertical orientation the panel sits to the right of the list.
