Breadcrumb

Semantic navigation trail. Renders as <nav aria-label="breadcrumb"> wrapping an ordered list. Compound: Breadcrumb › BreadcrumbList › BreadcrumbItem containing either a BreadcrumbLink (interactive ancestor) or a BreadcrumbPage (current, non-clickable, aria-current="page"). BreadcrumbSeparator and BreadcrumbEllipsis sit between items as role="presentation".

Simple trail

The current page is a BreadcrumbPage; everything ancestral is a link. Default separator is a chevron.

Collapsed with ellipsis
