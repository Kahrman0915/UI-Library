Toast

Global notification system. Toaster mounts once at your app root and subscribes to a global event bus; anywhere else in the tree the imperative toast() API fires notifications. Five semantic variants (default, info, success, warning, error), six positions, optional action/ cancel buttons, toast.promise() for async flows.

Setup

Mount the Toaster once, typically in your app root or a layout that persists across routes.

import { Toaster, toast } from '@ui/lib';

export function App() {
  return (
    <>
      <Toaster position="bottom-right" />
      <button onClick={() => toast.success('Saved.')}>Save</button>
    </>
  );
}

Same shape, semantic color per variant. Warnings and errors use role="alert"; the rest use role="status".

Imperative API

toast('Event saved.')

toast.success('Draft published.', {
  description: '2 minutes ago · main'
})

toast.error('Failed to publish.', {
  duration: 6000
})

// Sticky toast — no auto-dismiss.
const id = toast.loading('Rendering report…')
toast.dismiss(id) // dismiss one; toast.dismiss() dismisses all.

// Wire a toast to a promise.
toast.promise(fetch('/report'), {
  loading: 'Rendering report…',
  success: (r) => `Rendered in ${r.time}ms`,
  error:   'Failed to render.',
})
