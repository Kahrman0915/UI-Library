Progress

Linear progress bar. Root accepts value + max and auto-renders the header (via label and showValue) and the track+indicator. Or pass a compound children tree (ProgressLabel, ProgressValue, ProgressTrack, ProgressIndicator) for custom layouts. Set indeterminate to animate an unknown-duration state.

Sizes

Three heights — sm, default, lg.

Variants

Six semantic tones — default, brand, info, success, warning, error.

With header

Set label for a leading text and showValue to render the auto-formatted percentage on the right.
