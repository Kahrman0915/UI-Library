Badge

A small pill for statuses, counts, and labels. Unlike Button which composes variant × style, Badge flattens both dimensions into a single variant prop with 12 values: 2 theme-aware treatments (default filled, outline) that read --primary, plus error / success / warning / info / aiden each with a base and -outline variant.

Theme-aware

default (filled) and outline — both read --primary (neutral slate here, brand-colored inside a data-theme).

Category tags

The 17-hue palette via the category prop. Soft = -bg tint + AA-safe -text; solid = the vivid --category fill + inverted --category-foreground (white text in light mode / dark in dark, like the semantic badges). White dips under AA on the lighter hues — soft is the strictly-AA-safe option. For tags, labels, and table cells.
