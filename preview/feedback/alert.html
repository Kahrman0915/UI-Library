Alert

Inline, non-modal messaging. Five semantic variants (default, info, success, warning, error) each with two styles (default — soft-tinted background, outline — bordered only). Slots for Icon, title, description, action, and an optional close button via onClose. Uses role="alert" for warning/error, role="status" otherwise.

Variants — default style

Soft-tinted background using each variant's -light and -border tokens.
