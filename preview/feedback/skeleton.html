Skeleton

Animated placeholder for content that hasn't loaded yet. Three shapes (default, circle, text) plus explicit width / height. The shimmer sweep is CSS-only — background-position animation from off-screen right to off-screen left with an --ease-in-out curve.

Shapes

Rectangular by default (blocks, buttons). Circle for avatars/dots. Text-shape for typography with an aggressive border-radius.

Text block

Stack a few of the text-shape variants with varying widths to imitate a paragraph placeholder.

Card placeholder

Common pattern — hero image + avatar + title/subtitle.

Table rows

Data-table shell with 5 rows of shimmering cells while the API request is in flight.
