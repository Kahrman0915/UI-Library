Spinner

Loading indicator. A thin wrapper around lucide's LoaderCircle icon with our ui-spinner-rotate keyframe (900ms linear infinite). Colored via currentColor — the surrounding text color drives the arc, which lets one component blend into any context (button label, alert icon, brand-scoped section). Renders with role="status" and aria-label="Loading" for screen readers.

Sizes

The size prop is a pixel value, not a token key — pass any integer.

Color inheritance

The arc uses stroke="currentColor". Set color on the parent to change it.
