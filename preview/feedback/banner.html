Banner

A page-level announcement bar — full-bleed, edge-to-edge, with a coloured bottom hairline. Use it for site-wide notices (maintenance, new versions, promotions) that sit above the layout, as opposed to the inline Alert card. Five semantic variants reuse Alert's tint tokens; warnings and errors take role="alert", the rest role="status". Optional leading Icon, trailing action (composes Button), and a dismiss CloseButton via onClose. centered caps and centres the content for marketing bars.

Setup

import { Banner, Button } from '@ui/lib';

<Banner
  id="update"
  variant="info"
  Icon={Info}
  title="A new version is available."
  action={<Button id="reload" size="xsmall" style="outline" label="Reload" />}
  onClose={() => setShown(false)}
/>
