Empty

Centred empty-state block for a list, table, or panel with nothing to show. Static and composable: Empty root wraps an EmptyHeader (holding EmptyMedia, EmptyTitle, EmptyDescription) plus an optional EmptyContent for actions. EmptyMedia takes variant="icon" for a boxed muted tile, or variant="default" unboxed for a large glyph, image, or avatar.

Setup

import { Empty, EmptyHeader, EmptyMedia, EmptyTitle, EmptyDescription, EmptyContent, Button } from '@ui/lib';

<Empty>
  <EmptyHeader>
    <EmptyMedia variant="icon"><Inbox /></EmptyMedia>
    <EmptyTitle>No messages yet</EmptyTitle>
    <EmptyDescription>When someone sends you a message it'll show up here.</EmptyDescription>
  </EmptyHeader>
  <EmptyContent>
    <Button id="compose" label="Compose" />
  </EmptyContent>
</Empty>

With an action

The canonical shape — boxed icon media, title, description, and a single primary action in EmptyContent.

No messages yet

When someone sends you a message it'll show up here. Start a conversation to get going.

Two actions

A primary plus a secondary escape hatch. Anything inside EmptyContent is laid out in a row.

No documents

Create your first document, or import an existing folder from your computer.

Without an action

Omit EmptyContent entirely when the state is purely informational and there's nothing useful to do.

Unboxed media

The default media variant drops the muted tile — use it for a large glyph, an illustration, or an avatar.
