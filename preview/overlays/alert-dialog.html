AlertDialog

A confirmation that demands a choice. It's a thin preset of Dialog — same portal, focus trap, scroll lock, Escape-to-close and focus-restore — but with role="alertdialog" and two deliberate carve-outs: clicking the overlay does not dismiss it, and there's no header close button. The user must pick a footer action. Compose AlertDialog + AlertDialogHeader / Body / Footer.

Setup

import { AlertDialog, AlertDialogHeader, AlertDialogFooter, Button } from '@ui/lib';

<AlertDialog id="confirm" open={open} onClose={() => setOpen(false)}>
  <AlertDialogHeader id="confirm" title="Discard changes?"
    description="If you leave now, they'll be lost." />
  <AlertDialogFooter>
    <Button id="stay" style="ghost" label="Stay" onClick={cancel} />
    <Button id="discard" label="Discard" onClick={confirm} />
  </AlertDialogFooter>
</AlertDialog>
