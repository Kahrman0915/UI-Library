Drawer

Edge-anchored panel that slides in from any side. Composed of Drawer root plus DrawerHeader (prop-driven title / description and a built-in CloseButton), DrawerBody, and DrawerFooter. It reuses Dialog's portal, focus trap, scroll lock and Escape-to-close, and adds Tooltip's closed → open → closing state machine so the panel can animate out before it unmounts. Controlled via open / onClose; there's no drag-to-dismiss.

Reach for a Drawer over a Dialog when the content is a side task — filters, a detail pane, a form — that benefits from height and shouldn't feel like a hard interruption.

Setup

import { Drawer, DrawerHeader, DrawerBody, DrawerFooter, Button } from '@ui/lib';

<Drawer
  id="edit"
  open={open}
  onClose={() => setOpen(false)}
  side="right"
>
  <DrawerHeader title="Edit profile" description="Update your details." />
  <DrawerBody>…</DrawerBody>
  <DrawerFooter>
    <Button id="cancel" style="ghost" label="Cancel" />
    <Button id="save" label="Save changes" />
  </DrawerFooter>
</Drawer>

Sides

side takes top, right (default), bottom, or left. Each side has its own enter/exit keyframes — the animated property can't come from a var(), or the browser never fires animationend and the exit hangs.
