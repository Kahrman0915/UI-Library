Menubar

The desktop application menu bar — a horizontal row of triggers, each owning a menu. It reuses DropdownMenu wholesale: every menu is a controlled DropdownMenu and the surface parts are DropdownMenu's re-exported under Menubar names, so positioning, arrow-key item nav, Escape and outside-click all come free. Menubar itself only adds the coordination — single-open state, hover-to-switch once a menu is open, and roving tabindex with ArrowLeft / ArrowRight across triggers.

Setup

import {
  Menubar, MenubarMenu, MenubarTrigger, MenubarContent,
  MenubarItem, MenubarSeparator, MenubarShortcut,
} from '@ui/lib';

<Menubar id="app">
  <MenubarMenu value="file">
    <MenubarTrigger>File</MenubarTrigger>
    <MenubarContent>
      <MenubarItem>New tab <MenubarShortcut>⌘T</MenubarShortcut></MenubarItem>
    </MenubarContent>
  </MenubarMenu>
</Menubar>

The bar

A menu open

The open trigger keeps a held-down look while its menu is showing. Once any menu is open, hovering a sibling trigger switches to it — no second click.

Checkbox and radio rows

The item vocabulary is DropdownMenu's, so a Menubar menu can hold checkable rows and a radio group without any new parts.

Known v1 gaps

No submenus — ContextMenu is the only family with those. And ArrowLeft / ArrowRight move between triggers but not from inside an open menu; use hover, or Escape then arrow.
