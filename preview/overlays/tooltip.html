Tooltip

Small, delayed label describing a control. Compound: Tooltip + TooltipTrigger (clones its child) + TooltipContent. Configure side, align, sideOffset, and delayDuration (default 400ms). Includes direction-aware enter/exit animations via --motion-slide-sm and --ease-spring, and a state machine (closed | open | closing) that gracefully interrupts if you re-hover mid-close. Portals to document.body.

Four sides

Same trigger, four placements. In real code, one side prop controls this — the mockup shows all four for reference.
