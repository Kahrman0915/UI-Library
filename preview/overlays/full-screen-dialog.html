FullScreenDialog

A page rendered over the one the user was on — Help, Feedback, settings: anything that is a destination rather than a question. Covers the viewport edge to edge with no rounding, so nothing of the app shell shows through, then returns the user exactly where they were. Composed of a FullScreenDialog root plus FullScreenDialogHeader (required — it carries both the accessible name and the close X), FullScreenDialogBody and FullScreenDialogFooter.

It is a preset of Dialog: the portal, focus trap, scroll lock, focus restore and exit animation are all Dialog's. Dismissal is the X or Escape — no click-outside, so a stray click cannot discard a half-filled form. Use Dialog for one focused task in a card, Drawer for content that belongs beside the page, and AlertDialog for a question with two answers.

Over the workspace it was opened from

Before: a workspace with a sidebar and a tab row. After: the same frame with the page over it — the shell is completely covered, which is the whole point of choosing this over a Dialog. The header hairline runs edge to edge while the title aligns to the content column below it.
