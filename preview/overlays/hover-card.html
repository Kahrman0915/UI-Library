HoverCard

Rich preview panel that appears on hover — for user profiles, link previews, keyboard-shortcut lists, and other short-form context. Similar API to Popover but triggered by pointer hover with configurable open/close delays. Not appropriate for essential information (touch and keyboard users can't hover) — use Popover if the content is required.
