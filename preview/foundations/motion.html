Motion

Every animation in the library uses a token — never a raw ms or cubic-bezier value. Three primitives: durations (how long), easings (the curve), and slide distances (how far).

Durations

Same distance, same easing — only speed differs. --duration-fast for hover state changes, --duration-normal for menu / popover enters, --duration-slow for larger transitions like Dialog fades.

--duration-fast
100ms
--duration-normal
200ms
--duration-slow
300ms

Easings

Same duration (900ms), same distance — only the curve differs. Native CSS keywords for standard motion; two custom cubic-beziers for spring feel. --ease-spring is smooth with no overshoot; --ease-spring-strong overshoots slightly for the animate-ui-style pop (used on Checkbox icon scale).

--ease-default
ease
--ease-in
ease-in
--ease-out
ease-out
--ease-in-out
ease-in-out
--ease-spring
cubic-bezier(0.16, 1, 0.3, 1)
--ease-spring-strong
cubic-bezier(0.34, 1.56, 0.64, 1)

Slide distances

Tokenized translate values for portal-entering components. Tooltip and DropdownMenu slide in --motion-slide-sm on the axis they're aligning against. --tooltip-slide is a back-compat alias for --motion-slide-sm.

--motion-slide-sm
4px · Tooltip, DropdownMenu
--motion-slide-md
8px · Popover, HoverCard
--motion-slide-lg
12px · Dialog, Sheet
