ModeToggler

The light/dark switch. It owns the data-mode attribute on <html> — every token in tokens.scss swaps on [data-mode='light'] / [data-mode='dark'], so flipping this one attribute re-themes the whole page. Renders as a role="switch" button with aria-checked, and cross-fades a sun and moon icon rather than swapping them.

Mode is independent of theme: data-mode controls light vs dark, while data-theme='{code}' remaps --primary to a sub-brand. The two never clobber each other.

Setup

import { ModeToggler } from '@ui/lib';

// Drop it anywhere — usually a top bar. It writes data-mode
// onto <html> and persists the choice.
<ModeToggler id="mode" />

Variants

default is a filled control, outline adds a border on a transparent field, and ghost is chrome-free for dense toolbars.

Both modes

The same control in each state. The panel on the right carries data-mode="dark", which re-points every token inside it — the toggler's icon cross-fades to the moon and the surface flips with it.
