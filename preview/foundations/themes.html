Themes

Two independent axes. Mode is light / dark — set data-mode="light" or data-mode="dark" on <html> (the ModeToggler does this). Theme is a sub-brand's color — set data-theme="db" on <html> or any subtree.

A theme remaps a single token, --primary, to that brand's color. Every component that reads --primary — the primary button, checked checkbox, switch track, radio dot, active chip, progress — takes the color automatically. The main brand is the absence of data-theme: --primary stays neutral slate. Secondary / ghost / outline buttons, chrome, and tooltips stay neutral in every theme.
