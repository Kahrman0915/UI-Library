Palettes

Every color the library uses. Split into neutrals (chrome, text, borders), semantics (error, success, warning, info — each with a 4-token family), and categories (17-color chart palette with matching -bg tinted backgrounds).

Neutral core

The base look. Every component that isn't a semantic variant lives on this ramp. Theme-swappable via [data-mode="light"] / [data-mode="dark"] on the <html> element.

Semantic families
