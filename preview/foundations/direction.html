Direction — RTL / LTR

DirectionProvider sets the dir attribute on a display: contents wrapper — layout-neutral, so it adds no box — and shares the direction through context for the components that position in JS. useDirection() reads it.

No component needed changing to support this. The library already leans on CSS logical properties (margin-inline, border-inline-start, inset-inline) and flex rows, so wrapping any subtree in dir="rtl" mirrors it for free: icons swap sides, rows reverse, text right-aligns.

Setup

import { DirectionProvider, useDirection } from '@ui/lib';

<DirectionProvider dir="rtl">
  <Checkout />
</DirectionProvider>

// anywhere inside
const dir = useDirection(); // 'ltr' | 'rtl'

Scope it as narrowly as you like

The provider is not global. Wrap the whole app, or one panel — a right-to-left comment thread inside a left-to-right dashboard is a wrapper, not a rebuild.
