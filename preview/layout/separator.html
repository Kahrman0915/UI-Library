Separator

A semantic <div role="separator"> for visually and structurally dividing content. Horizontal or vertical orientation, optional inline label for "or"-branches. Set decorative to drop the role="separator" when the divider is purely visual (recommended when adjacent content already conveys the boundary structurally).

Horizontal

Default orientation. Full-width 1px hairline using --border.
