Code

Two ways to show source. Code is an inline <code> snippet for running text; CodeBlock is a fenced sample with an optional filename header and a copy button (composes Button, writes to navigator.clipboard). No syntax highlighting — that would need a dependency.

Inline

Install with npm install @ui/lib, then import the styles once: import '@ui/lib/styles.css'. Every component is a named export from @ui/lib.

Block with filename

App.tsx 
import { Button } from '@ui/lib';

export function App() {
  return <Button id="save" label="Save" />;
}

Without a filename

The copy button stays flush right on its own.
