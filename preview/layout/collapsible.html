Collapsible

A one-off disclosure primitive. Unlike Accordion which manages a group, Collapsible is a single toggleable region. Root exposes open / defaultOpen / onOpenChange. CollapsibleTrigger clones its child button and wires aria-expanded, aria-controls, and the toggle handler. CollapsibleContent stays mounted with the same grid-based height animation as Accordion.

Open

Default open state; the caret rotates 90° via the data-state="open" attribute on the trigger.

These panels stay mounted so keyboard focus and screen-reader announcements behave correctly. When closed they get hidden and inert.

Closed

Closed state — content is present in the DOM but visually collapsed to 0fr grid row.

Composition

Any element can be the trigger — the component clones its single child and adds the wiring, so you keep control of markup and styling.
