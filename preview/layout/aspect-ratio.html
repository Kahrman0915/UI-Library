AspectRatio

Locks a box to a width-to-height ratio so media never causes layout shift while it loads. A pure-CSS layout primitive — one <div> using the native aspect-ratio property, no JS. Pass the ratio as a division expression (16 / 9, 4 / 3, 1). Direct img / video / iframe children fill and cover the box.

Setup

import { AspectRatio } from '@ui/lib';

<AspectRatio ratio={16 / 9}>
  <img src="/cover.jpg" alt="Cover" />
</AspectRatio>

Ratios

The box sizes its own height from the width it's given.

4 / 3
