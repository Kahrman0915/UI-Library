Accordion

Vertical stack of collapsible sections. Two modes: type="single" (one open at a time, optionally collapsible) or type="multiple" (any subset open). Compound API: Accordion › AccordionItem value identifier › AccordionTrigger + AccordionContent. Height animates smoothly via grid-template-rows with a two-layer clip — no JS measurement, no ResizeObserver.

Single, collapsible

Only one section open at a time. The open item can be re-clicked to close everything.

A React component library. No CSS framework, no third-party UI libraries — everything is native React plus SCSS in a ui--prefixed BEM namespace. 33 components ship today, all styled through src/styles/tokens.scss.
Put data-theme="{code}" on a subtree. Components reading --primary pick up that theme's color automatically.
Only lucide-react. react and react-dom are peer dependencies.

Multiple

type="multiple" lets any subset be open at once. Useful for checklists and settings groups.
