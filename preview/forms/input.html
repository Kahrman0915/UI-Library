Input

Single-line text input. Composes Label internally when label is set. Three sizes (sm, default, lg), optional IconLeft / IconRight slots, and an error boolean that colors the ring and shows errorMessage below. .ui-input-wrap owns the border and focus-within ring — Textarea, Select, and Combobox all reuse this same wrap.

States

Default, filled, error, disabled — all with a matching label above.

Must be lowercase with only letters, numbers, and hyphens.

Sizes

The size prop applies to both the label and the input.

With icons

IconLeft and IconRight render inside the wrap. Icons inherit currentColor.
