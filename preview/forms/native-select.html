NativeSelect

A styled native <select> — distinct from the floating Select. Use this when you want the platform's own dropdown: it's the right call on mobile, inside dense forms, and anywhere the OS picker beats a custom listbox. It composes <Label> and reuses Input's .ui-input-wrap / .ui-input-field, so borders, focus ring, hover, error and disabled states all match the rest of the form controls. Native chrome is stripped and a custom chevron overlaid. Takes size, error and required just like Input.

Setup

import { NativeSelect, NativeSelectOption, NativeSelectOptGroup } from '@ui/lib';

<NativeSelect id="status" label="Status">
  <NativeSelectOption value="">Select a status…</NativeSelectOption>
  <NativeSelectOption value="todo">Todo</NativeSelectOption>
  <NativeSelectOption value="done">Done</NativeSelectOption>
</NativeSelect>

Default

Label, placeholder option, and a disabled option. The chevron is decorative — the native picker still opens on click.

Sizes

sm, default, and lg — the size flows to both the label and the field, matching Input.

Grouped options

NativeSelectOptGroup renders a native <optgroup> — the platform draws the group headings.

Required + error

required adds the * via the shared Label, and error swaps the wrap to its error border and wires aria-invalid plus aria-describedby to the message.

Please choose a country.

Disabled

Disabled inherits Input's disabled treatment — muted text and a non-interactive field.
