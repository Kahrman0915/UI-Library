Field

Form-composition primitive. Ten exports orchestrate labels, descriptions, errors, and grouping. Use FieldSet + FieldLegend as the semantic root, FieldGroup to stack rows, and Field to wrap each control with its label + description + error slot. orientation switches between vertical (label above) and horizontal (label beside).

Vertical field

Default orientation — label, control, description stack top-down. FieldError appears when invalid.

Shown on invoices and shared documents.

Horizontal (label + control side by side)

Compact layout for settings pages — the label sits on the left with the control on the right.

Two-factor authentication

Require a code from your authenticator app on every sign-in.

Invalid + FieldError

Setting invalid tints the label and border. FieldError pipes messages via role="alert" for screen readers.

  • Must be lowercase.
  • Only letters, numbers, and hyphens allowed.

FieldSet + FieldLegend

Group semantically-related controls under a legend. Two visual variants for the legend.
