Slider

Pick a number, or a pair of numbers, along a continuous track. One thumb by default; pass range for two. Values snap to step and clamp to min / max. The filled portion always runs from the lower value to the upper one — in single mode that's simply min → value.

Each thumb is a role="slider" element with its own aria-valuemin / aria-valuemax / aria-valuenow. In range mode those bounds stop at the neighbouring thumb, so assistive tech announces the real distance the thumb can travel rather than the full scale.

Setup

import { Slider } from '@ui/lib';

// Single value
<Slider id="volume" label="Volume" defaultValue={40} showValue />

// Two thumbs — value is [lower, upper]
<Slider
  id="price"
  label="Price range"
  range
  defaultValue={[20, 70]}
  formatValue={(v) => `$${v}`}
  showValue
/>

Single value

The default. showValue prints the current value beside the label; formatValue controls how it reads.

40

Range

range renders two thumbs and makes the value a [lower, upper] tuple. The thumbs may meet but never cross, and dragging one never shoves the other along with it. Each carries its own accessible name — Minimum and Maximum — while the group is labelled by the field.

$20 – $70

Sizes

sm, default, and lg — the track height and thumb scale together, matching Progress's track scale.

With a description

The label composes the shared <Label>, so description and the required indicator behave exactly as they do on Input and Textarea.

Disabled

Thumbs drop out of the tab order, pointer and keyboard input are ignored, and the filled portion goes muted.

Every thumb is focusable and fully operable without a pointer.
