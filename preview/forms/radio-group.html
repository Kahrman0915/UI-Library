RadioGroup

Native <input type="radio">s wired together as a group. Compose RadioGroup with RadioGroupItem children. value / defaultValue select the current item; onValueChange(next) reports changes. Group-level label, description, required, and orientation (vertical / horizontal) apply to all items.

Vertical

Default orientation. Group label lives in a header above the items.

Horizontal

Set orientation="horizontal" for compact chip-like layouts.
