Toggle

A two-state button — pressed or not — exposing aria-pressed. Use it for formatting controls (bold, italic) or any on/off action that lives inline. Distinct from Chip (a rounded filter pill): Toggle is a squared control whose pressed state uses the neutral --accent fill, so it never competes with the themed primary CTA. variant = default / outline, size = sm / default / lg. Controlled via pressed or uncontrolled via defaultPressed.

Setup

import { Toggle } from '@ui/lib';
import { Bold } from 'lucide-react';

<Toggle id="bold" IconCenter={Bold} aria-label="Bold" defaultPressed />
