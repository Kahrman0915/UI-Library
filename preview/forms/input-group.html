InputGroup

Composes an input with leading or trailing addons — icons, currency prefixes, embedded buttons, unit suffixes. Reuses Input's .ui-input-wrap so the border, focus-within ring, and error state match exactly. Addons use CSS order to sit on either side while the input stays first in DOM order for tab flow.

Leading + trailing text addons

Common pattern — currency prefix and unit suffix around a numeric input.

Trailing button

InputGroupButton is a small flat button sized to fit inside the wrap — good for copy-to-clipboard, apply, and reveal-password buttons.

Error state

Error propagates to the wrap the same way as Input — the ring turns error-red, and consumer error text is handled outside the group.
