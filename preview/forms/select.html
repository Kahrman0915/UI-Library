Select

Dropdown for choosing one value from a static list. Uses the same .ui-input-wrap border and focus ring as Input for visual consistency. Trigger displays the current value (or a placeholder in --muted-foreground); content is portalled and positioned. Options support optional groups and separators.

Closed states

Default, with a chosen value, and error.

A team is required to continue.

Open, with groups

Static mock of the open state — one item is selected (checkmark). Groups are separated by Separator.
