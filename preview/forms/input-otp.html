InputOTP

A segmented one-time-code field. The slots are presentation — underneath sits a single real <input> holding the whole value, which is what makes native paste, mobile one-time-code autofill and text selection work without per-field focus juggling.

Setup

import { InputOTP } from '@ui/lib';

<InputOTP
  id="verify"
  label="Verification code"
  length={6}
  groupSize={3}
  onComplete={(code) => submit(code)}
/>
